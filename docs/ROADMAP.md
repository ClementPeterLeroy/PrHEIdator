# Predator roadmap

## v2.0 ? Game Rebirth

Historical modernization milestone: modular local application, five implemented
school modes, centralized paths, tests and archived source. Preserved in the
changelog and v2.0 audit/validation/delivery snapshots. No historical release
dates or Git history are inferred.

## v2.1 ? Arcade Renaissance

Delivered as one cumulative local patch: Predator naming, retro-neon UI,
scaled/resizable 16:9 rendering, six home actions, pre-match controls, countdown,
universal pause/restart, deliberate results, working options and local JSON
preferences. All five existing modes plus Fun's six power-ups are implemented.
Assets are consolidated under assets/ and verified. Lightning remains reserved.

Owner acceptance remains subject to real gameplay, visual review and the
unresolved asset permissions/source-license decisions. The owner handles all
version control and publication manually.

## v2.2 ? Proposed, not begun

- Human balance review of Fun intervals, geometry/speed effects and the bot.
- Physical four-player keyboard rollover testing and remappable controls.
- Broader accessibility review, including scaling, contrast and reduced motion.
- Additional platform/clean-install checks and packaging if approved.
- Asset provenance resolution, accurate attribution and owner-selected code license.
- CI after the owner establishes the repository workflow.

No online multiplayer, neural-network training, different engine or Lightning
implementation is included in this work. New gameplay requires separate scope.
